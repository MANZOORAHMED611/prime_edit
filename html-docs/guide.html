User Guide

Get started with PrimeEdit — a fast native text editor for Linux.

Getting Started

Installation

PrimeEdit requires Qt 6 (or Qt 5) development libraries and CMake.

# Ubuntu / Debian
sudo apt install qt6-base-dev qt6-tools-dev qt6-svg-dev cmake build-essential

# Fedora
sudo dnf install qt6-qtbase-devel qt6-qtsvg-devel cmake gcc-c++

# Arch Linux
sudo pacman -S qt6-base qt6-svg cmake base-devel

Build & Run

git clone https://github.com/MANZOORAHMED611/prime_edit.git prime-edit
cd prime-edit
mkdir build && cd build
cmake ..
make -j$(nproc)
./PrimeEdit
Tip: After building, PrimeEdit automatically installs its icon and desktop launcher to ~/.local/share/. You can find it in your application menu by searching "PrimeEdit".

First Launch

When you open PrimeEdit for the first time:

  • The editor opens with the Notepad++ theme (white background, blue keywords)
  • An empty Untitled 1 tab is ready for typing
  • The toolbar shows common actions as 16x16 icons in a single row
  • The status bar at the bottom shows line/column, encoding, and line ending
Unsaved work is safe. If you close PrimeEdit with unsaved content in any tab — even untitled tabs, and tabs in either split pane — it is preserved without a prompt and restored the next time PrimeEdit starts. See Unsaved Work & Recovery.

Basic Editing

  • New file: Ctrl+N or double-click empty tab bar area
  • Open file: Ctrl+O — or drag files from your file manager
  • Save: Ctrl+S — prompts for untitled files
  • Close tab: Ctrl+W, click the X, or middle-click the tab
  • Switch tabs: Ctrl+PgUp / Ctrl+PgDn

Multi-Cursor Editing

Multi-cursor editing lets you type, delete, and paste at multiple positions simultaneously.

Adding Cursors

  • Alt+Click anywhere in the document to place an additional cursor
  • Ctrl+D selects the next occurrence of the current word and adds a cursor there
  • Ctrl+Shift+L selects all occurrences of the current word at once
  • Press Escape to return to a single cursor

What Works with Multi-Cursor

  • Typing, deleting, and pasting text
  • Auto-close brackets and quotes (inserted at all cursor positions)
  • Line operations (duplicate, delete, move)
  • Toggle comments

Column Selection

Hold Alt and drag with the mouse to create a rectangular (column) selection. Type to insert text at every line. Use Alt+C to open the Column Editor dialog for text or number sequence insertion.

Atomic undo: All multi-cursor edits are grouped — one Ctrl+Z undoes the entire operation across all cursor positions.

Split-Screen

View two files side by side. Each document is open in one pane at a time.

Splitting

  • Ctrl+\ splits the editor vertically (side by side)
  • Ctrl+Shift+\ splits horizontally (top and bottom)
  • F6 switches focus between panes
  • Ctrl+Alt+\ closes the current split

A new split opens an empty second pane. Fill it by moving tabs into it.

Moving Tabs

Select a tab and choose View > Move to Other View. If the editor is not split yet, this splits it and moves the tab into the new pane. When the second pane's last tab closes, the split closes.

Closing Tabs

A tab's close button closes the tab it belongs to, in whichever pane that is, even while the other pane has focus.

Search & Replace

Quick Search

Ctrl+I opens the incremental search bar — a compact bar that highlights matches as you type. Press Enter for next match, Shift+Enter for previous, Escape to close.

Full Search Dialog

Ctrl+F opens the tabbed search dialog with four tabs:

  1. Find — Find Next, Count, Find All in Current Document, Find All in All Open Documents
  2. Replace (Ctrl+H) — Replace one, Replace All, Replace in All Open Documents
  3. Find in Files (Ctrl+Shift+F) — Search across files on disk with directory picker and filters
  4. Mark — Highlight all matches with yellow background. Optionally bookmark marked lines.

Search Modes

  • Normal — literal text matching
  • Extended — recognizes \n (newline), \t (tab), \r (return), \xNN (hex byte)
  • Regular Expression — full regex with backreferences in replace (\1, $1)

Search Results Panel

When you use "Find All", results appear in a bottom panel grouped by file. Double-click any result to jump to that location.

Code Intelligence

PrimeEdit provides smart editing features through its built-in LSP client, auto-completion engine, and snippet system.

LSP Setup

Install the language server for your language. PrimeEdit connects automatically when you open a file.

LanguageServerInstall Command
C / C++clangdsudo apt install clangd
Pythonpylsppip install python-lsp-server
JavaScript/TypeScripttypescript-language-servernpm i -g typescript-language-server
Rustrust-analyzerrustup component add rust-analyzer
Gogoplsgo install golang.org/x/tools/gopls@latest

For other languages, create ~/.config/PrimeEdit/lsp-servers.json:

{
  "python": {"command": "pylsp", "args": []},
  "c++": {"command": "clangd", "args": ["--background-index"]},
  "rust": {"command": "rust-analyzer", "args": []}
}

Completions

  • Ctrl+Space to trigger manually, or type 3+ characters for automatic popup
  • Enter or Tab to accept, Escape to dismiss
  • Sources (in priority order): LSP completions, language keywords, document words

Diagnostics

LSP diagnostics appear as wave underlines in the editor — red for errors, yellow for warnings. Hover over an underline (or press Ctrl+K) to see the diagnostic message.

Snippets

Type a snippet prefix and press Tab to expand. PrimeEdit includes built-in snippets for common language patterns. Snippet completions appear in the auto-complete popup with a snippet icon.

Block Evaluation (AI)

Select text and press Ctrl+Shift+E to send it to an LLM endpoint (Ollama by default). An inline diff appears — press A to accept or Escape to discard. Configure the endpoint via Tools > Configure Endpoint.

Git Integration

PrimeEdit provides built-in Git support for common workflows without leaving the editor.

Gutter Indicators

When you edit a file in a Git repository, colored indicators appear in the left gutter:

  • Green — added lines (new content)
  • Yellow — modified lines (changed from last commit)
  • Red — deleted lines (a triangle marker shows where lines were removed)

These indicators update automatically as you type.

Committing

Git > Commit (Ctrl+Shift+G) opens the commit dialog:

  • File list with staging checkboxes — select which files to include
  • Diff preview for each file — review changes before committing
  • Commit message editor with subject/body separation

Branch Switching

Git > Switch Branch shows a list of local branches. Select one to switch. Open files that changed between branches show the notification bar, so you choose whether to reload each one.

Remote Editing

Edit files on remote servers over SSH without leaving PrimeEdit.

Setting Up a Connection

  1. Open File > Open Remote (Ctrl+Shift+O)
  2. Click Add Connection and enter hostname, username, port, and key file path
  3. Browse the remote filesystem and open files

Editing Remote Files

Remote files open like any local file. When you save (Ctrl+S), changes are automatically uploaded to the remote server. The tab title shows the remote path with a network icon to distinguish remote files from local ones.

SSH keys: PrimeEdit uses your SSH key for authentication. Make sure your key is added to ssh-agent or specify the key file path in the connection settings.

Themes

Open Settings > Preferences, go to the Appearance tab, and select a theme from the dropdown. The change applies instantly — including syntax highlighting colors.

Available Themes

Notepad++ (default), Default Light, Default Dark, Olive, Monokai, Dracula, Nord, Solarized Light, Solarized Dark.

Custom themes can be created as JSON files and imported via the Theme Editor.

Macros

Record a sequence of actions and replay them.

  1. Press F9 to start recording
  2. Perform your editing actions (typing, navigation, etc.)
  3. Press Shift+F9 to stop recording
  4. Press F10 to play back the macro

Run Multiple Times

Via Macro > Run Multiple Times: enter a count, or choose "Run until end of file" to repeat the macro until the cursor reaches the last line.

Save & Load

Macros can be saved to disk and loaded later. Saved macros persist across restarts via ~/.config/PrimeEdit/macros.json.

Large Files

PrimeEdit handles files that other editors cannot open.

  • Files over 50 MB, and minified files (almost no line breaks) over 20 MB, open as a partial view: only part of the file is loaded
  • A partial view is read-only. Save, Save As, Save All and the encoding and line-ending changes are disabled for that tab, and the notification bar says so when the file opens
  • A 1GB file uses only 95MB of memory (verified by stress testing)
  • Scrolling is smooth — only visible lines plus a buffer are in memory
No special action needed. Just open the file normally. PrimeEdit detects the file size and switches modes automatically.
Why a partial view cannot be saved: saving it would replace the whole file on disk with the part that is loaded, and the rest would be lost.

Saving Files

A save either writes the whole file or leaves the file on disk unchanged.

When a save fails

  • An error dialog names the file and the reason, and says the file on disk is unchanged.
  • The tab stays modified. Undo does not make it look saved, so the close prompt still asks about it.
  • A file without write permission (for example mode 0444) cannot be saved. Use Save As to write a copy elsewhere.

Save Directly (Not Atomic)

PrimeEdit normally writes to a temporary file and swaps it in, so an interrupted save never leaves a half-written file. When the folder does not allow that temporary file but the file itself is writable, the error dialog offers Save Directly (Not Atomic). It writes over the file in place; if that write is interrupted, the file can be left incomplete. It is never offered after an error such as a full disk, where writing in place would destroy the original.

A hard-linked file, or a file owned by another user, is always written in place so the link and the owner are kept. The notification bar says when that happened.

Closing a tab with unsaved changes

  • Every modified tab asks before it closes. Save saves that tab's file, whichever pane it is in and whichever pane has focus.
  • A read-only document, such as a partial view, cannot be saved, so its prompt offers only Discard or Cancel.
  • Save All saves every modified tab in both panes and skips read-only ones.

Save As for a recovered draft

If a draft's original file could not be reopened at startup, the draft opens as an untitled tab. Save As then suggests the original file's path.

Files changed by another program

  • When another program changes an open file, the notification bar says so and offers Reload and Keep mine. Your own saves never raise it.
  • If the tab has unsaved changes, the button reads Reload (discard my changes). Nothing reloads until you choose.
  • If the changed file is in a background tab, the bar appears when you switch to that tab.
  • Keep mine keeps your text; the next change on disk asks again. Reload replaces the tab's text with the file on disk, and the tab is no longer modified.

Encodings

The status bar shows each file's encoding by its standard name: UTF-8, UTF-8-BOM, UTF-16LE-BOM, windows-1252, Shift_JIS, ISO-8859-1 and so on. The Encoding menu checks the matching Encode in item; an encoding with no item, such as windows-1252, leaves none checked.

Reopen with Encoding

Detection reads the whole file. It looks for a byte order mark, then for UTF-16 without one, then checks for valid UTF-8, then guesses windows-1252, Shift_JIS or ISO-8859-1. It cannot recognise ISO-8859-6 or windows-1256, so such a file opens as something else and its text looks wrong. To correct it, choose Encoding > Reopen with Encoding... (the first item in the menu, and also in the status-bar encoding menu) and pick the right encoding. This decodes the file's bytes again; it does not convert or save anything. If the tab has unsaved changes, you are asked before they are discarded.

Opened read-only? If a file's bytes do not decode exactly in the detected encoding, PrimeEdit opens it read-only so a save cannot change bytes you did not edit. The notification bar says so and has a Reopen with Encoding... button.

Converting (Encode in ...)

  • Conversions are disabled for read-only documents (a lossy decode, a partial view, or a file without write permission), because the converted file could not be saved. Use Reopen with Encoding... to read such a file differently.
  • Before converting, PrimeEdit checks that every character can be written in the new encoding. If some cannot (for example Arabic text and Encode in ANSI), a dialog gives the count and the first five positions as line:column, and offers Cancel or Replace N characters with ?.
  • Replace is one edit, so a single Ctrl+Z undoes it. Nothing is written until you save.
  • Encode in UCS-2 BE BOM and UCS-2 LE BOM save as UTF-16 with a byte order mark (UTF-16BE-BOM, UTF-16LE-BOM).
  • A conversion is a change: the tab stays modified until you save, even if you undo every text edit.
  • A file that had a byte order mark keeps it when you save.

Characters the encoding cannot hold

If you type text the file's encoding cannot hold, Save does not write the file. A dialog names the count and positions and offers Save as UTF-8, Replace N characters with ?, or Cancel.

Line endings

A new file, and a file with no line break at all, uses the default line ending from Preferences (LF unless you change it).

Mixed line endings

A file whose lines end in a mix of CRLF and LF is saved with the ending most of its lines use. The notification bar says so at the first save of that document, for example Mixed line endings in 'notes.txt' will be saved as CRLF.

Special spaces

No-break spaces (U+00A0) and line separators (U+2028) are kept as they are when you save, when you use Replace All, and when you use the line commands (remove empty or duplicate lines, trim whitespace, EOL to space, tab and space conversion).

Read-Only Documents

A document opens read-only when saving it could change bytes you did not edit:

  • a partial view of a large file (see Large Files);
  • a file whose bytes do not decode exactly in the detected encoding (see Encodings).

A read-only document refuses typing, but you can still move around, select and copy. Save is refused and says why. If the document had unsaved changes before it became read-only, closing it still asks, with Discard or Cancel.

A file without write permission opens normally, but Save reports that the file is read-only and leaves it unchanged; use Save As. Encoding and line-ending conversions are disabled for all of these.

Code folding never changes text

Folding only hides lines. Saving a document with folded regions writes all of its text. A fold opens by itself when the cursor, a Find match, Go to Line or a multi-cursor edit reaches inside it, when you delete its header line, and when undo changes text inside it.

Unsaved Work & Recovery

  • Every edit marks the tab as modified at once, so the close prompt and the unsaved-document cache always see it.
  • Unsaved documents, in both split panes and including untitled tabs, are written to the cache every 30 seconds and when PrimeEdit closes. A crash loses at most the last 30 seconds of typing.
  • The list of open files, with their bookmarks, folds and the active tab, is recorded within 5 seconds of any change, and nothing is written while nothing changes. After a crash, a kill or a power loss, the files you had open are reopened on the next start when Restore previous session on startup is on. Drafts are cached as described above, unchanged.
  • The cache is restored on every start, also when you open PrimeEdit with files on the command line. Restore session on startup controls only whether the files you had open are reopened.
  • If a draft's original file can no longer be opened, the draft is restored in a new untitled tab and the notification bar names the file. Save As suggests the original path.
  • A cache entry that cannot be read is moved to ~/.local/share/PrimeEdit/sessions/unsaved.corrupt/ and kept, never deleted.

Opening files while PrimeEdit is running

Only one PrimeEdit runs per user profile. Launching it again, for example from a file manager, opens the files in the running window and brings it to the front. If the running window does not answer, the second launch reports PrimeEdit is running but not responding and exits without touching your unsaved work.

Damaged settings and session files

Settings, sessions and macros are written atomically, so an interrupted write leaves the previous file intact. If settings.json, session.json, a named session or macros.json cannot be read, PrimeEdit copies it to <name>.corrupt-<yyyyMMdd-hhmmss>, leaves the original as it is, and uses defaults in memory. Nothing is written to that file until you change something; for session.json, until you open or close a file, or change a bookmark, a fold or the active tab. Moving or resizing the window alone does not count.

Markdown

  • Ctrl+Shift+M (View > Markdown Preview) cycles a Markdown tab through source, side by side with a live preview, and rendered only. Esc in the rendered view returns to the source.
  • Ctrl+Shift+H (View > Markdown Outline) shows or hides the Outline panel, a heading tree that jumps to each section.

Plugins

PrimeEdit supports a plugin system for extending the editor with custom functionality.

Plugin Locations

  • User plugins: ~/.config/PrimeEdit/plugins/
  • System-wide plugins: /usr/lib/prime-edit/plugins/

Managing Plugins

Open Tools > Plugins to see all installed plugins. Toggle the checkbox next to any plugin to enable or disable it. Changes take effect immediately.

Writing a Plugin

Plugins are Qt shared libraries (.so) implementing the PluginInterface. Each plugin receives an EditorAPI object with access to:

  • Buffer API — read and modify document content
  • File API — open, save, and manage files
  • UI API — add menus, toolbar buttons, and panels
  • Settings API — read and write configuration

See the Technical Documentation for the full plugin API reference.

Editor Preferences

  • Font family — choose any monospace font (default: DejaVu Sans Mono)
  • Font size — 6pt to 72pt
  • Tab width — 1 to 16 spaces
  • Insert spaces — tabs vs spaces
  • Word wrap, line numbers, highlight current line, minimap

File Defaults

  • Default encoding and line ending
  • Trim trailing whitespace and insert final newline on save
  • Restore session on startup — reopens the files you had open. Unsaved drafts are restored on every start regardless.
Settings are saved to ~/.config/PrimeEdit/settings.json and take effect immediately. Click Apply to see changes without closing the dialog. To reset everything, delete the settings file and restart PrimeEdit.
